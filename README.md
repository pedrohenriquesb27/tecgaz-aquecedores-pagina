# TecGaz Aquecedores - Página de Vendas

Página de vendas oficial da TecGaz Aquecedores em Guarulhos - SP.
Criado com React, TanStack Start, Vite e Tailwind CSS.

## Configuração Vercel
O projeto possui o arquivo `vercel.json` configurado para evitar erros 404 em deploys na Vercel (`outputDirectory: ".output/public"`).
